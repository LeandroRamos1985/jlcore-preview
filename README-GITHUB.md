# JL+CoRE Premium Preview V2 — GitHub Pages

This is a static HTML/CSS/JS preview and can be published directly with GitHub Pages.

## Publish
1. Create a GitHub repository, e.g. `jlcore-preview`.
2. Upload every file and folder in this directory to the repository root.
3. In GitHub: Settings → Pages → Deploy from a branch → `main` → `/ (root)`.
4. The preview will work at `https://YOUR-USERNAME.github.io/jlcore-preview/`.

## Important before production
- Keep `noindex,nofollow` while this is only a sales/demo preview.
- Replace screenshot-derived images in `assets/images/` with approved original high-resolution files from JL+CoRE.
- Download and self-host final approved hero video instead of relying on a remote Pexels URL.
- Verify team, awards, brokerage/legal disclosures, testimonials, office/contact details and service areas.
- Connect live IDX/MLS, CRM/email routing, analytics, Search Console and anti-spam.
- Remove preview copy and run the complete 72-item quality gate before launch.
